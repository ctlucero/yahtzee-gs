# GS8 - an original 9-pixel proportional bitmap font for the Yahtzee port,
# drawn in the spirit of the Apple IIgs system font (it is not Shaston):
# chunky two-pixel stems, sized so the original's text layouts fit.
# Format: "char <c>" (or "code <n>") then 9 rows: 7 above the baseline,
# 2 below. '#' = ink, '.' = paper. Each glyph's width is its row length;
# one blank column of spacing is added when drawing.
